ORVIN Privacy Policy

ORVIN is a private automation tool operated by a single creator to upload and schedule videos to the creator's own YouTube channel.

Use of YouTube API Services

ORVIN uses YouTube API Services to upload videos and set their metadata (titles, descriptions, tags, thumbnails, publish schedule) on the creator's own channel, and to read that channel's own video statistics. By using ORVIN, the channel owner agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

Data collected

ORVIN has no users other than the channel owner. It does not collect, store, sell or share any personal data of other people.

Storage

Authorization tokens are stored securely in the creator's private n8n account and are used only for the actions above.

Deleting data and revoking access

Access can be revoked at any time at myaccount.google.com/permissions. When access is revoked or the tool is no longer used, stored tokens are deleted from the n8n account.
